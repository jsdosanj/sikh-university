# ADR-0003: Sikhi University · Institute of Technology (the engineering wing)

**Status:** Accepted · **Date:** 2026-08-28 · **Plan:** `WORLD-CLASS-IOT-PLAN.md` (four gstack reviews cleared)

## Context
Sikhi youth worldwide already use and trust sikhiuni.com. There is no path inside it to the
software / AI-engineering skills that pay. freeCodeCamp / boot.dev / "AI Engineering from
Scratch" teach this well and free — so the content is not the differentiator.

## Decision
Add a **namespaced wing at `/institute/*`** — "Sikhi University · Institute of Technology" —
with its own dark, retro-futurist design system (`DESIGN-INSTITUTE.md`), an in-browser code
lab, and a curriculum built from **openly-licensed sources** plus our own additions.

**The wedge (why us):** the Sikh community's own institution now teaches the skills that pay,
in the community's voice, and points graduates at *building for the Panth* (a capstone of
real community tools). That is the part freeCodeCamp structurally cannot have.

**Ship shape:** a *Full Minimum Lovable Institute* — AISF phases 0, 2, 3, 7, 11, 13, 14
(~149 lessons), the sikhi.io coding courses, the guide, and the capstone. The other 13 AISF
phases, the Open Source Atlas, and two more explore booths are deferred to depth waves after
a cohort soft-launch.

## Architecture
- **Same spine, extended, not forked.** `Base.astro` gains an `institute` prop (fonts,
  `body[data-institute]`, translate opt-out, dark-default). `web/src/styles/institute.css`
  is scoped entirely under `body[data-institute]` — inert on the rest of the site.
- **Data:** `web/src/data/institute/` — `manifest.json` (the spine) + `imported/<track>/`
  (from AISF, regenerated by `scripts/sync-aisf.mjs`, committed) + `ours/<track>/` (our seva
  intros, lab checks — a re-sync never touches these). Lesson JSON ships as static assets
  (~5 MB, under the Cloudflare limit — no R2 for the MLI).
- **Quizzes:** server-graded by `/api/quiz` against `functions/api/_institute-quiz-keys.js`
  (generated, server-only, CI diff-gated). Same anti-forgery guarantee as the main catalogue.
- **The code lab:** a lean `<textarea>` editor (not CodeMirror — the strict `style-src`),
  JS in a same-origin Web Worker (10 s `terminate()` cap), HTML in a
  `<iframe sandbox="allow-scripts">` with checks run in-frame. Python via Pyodide is a later
  wave.
- **CSP:** `wrangler.toml` `run_worker_first = ["/institute", "/institute/*"]`; `worker.js`
  widens the asset layer's own hash-hardened CSP for those paths only —
  `'wasm-unsafe-eval'` + jsDelivr (Pyodide, mermaid) in `script-src`/`connect-src`,
  `frame-src 'self'` (the preview iframe). The rest of the site is unchanged.
- **Booths** (`/institute/explore`): link-out only, each skinned to its source, no logos, a
  "not affiliated" line. freeCodeCamp for the MLI.

## Tradeoffs (explicit)
- ✅ A real skills pipeline for the community, in a trusted platform, built on lawful sources.
- ➖ Large permanent maintenance surface (149+ lessons, two engines, sync pipelines).
- ➖ "Premium" depends on the first ~10 lessons getting real editorial polish — budgeted (C5).
- The credential is a *completion record*, verifiable at `/verify`, with no implied industry
  recognition.

## Consequences
- `/institute/*` stays `noindex` until a cohort soft-launch validates the wedge (C6), then
  it is promoted from the homepage and added to the sitemap.
- AISF updates are re-pulled by `scripts/sync-aisf.mjs`; our `ours/` sidecars survive.
